팀별 월간 일정 혼잡도

리그와 컵대회 일정, 경기 사이 휴식일을 달력에서 확인하세요.

일정 정보는 검증 상태가 다른 자료를 통합한 실험적 분석입니다. 컵대회 원본 결과는 경기별 독립 교차검증이 완료되지 않았으며, 이 수치는 승률 예측 모델에 사용되지 않습니다.

선택한 달의 일정 요약

이번 달 경기 수—
최단 경기 없는 날—
7일 최다 경기—
짧은 경기 간격 (3일 이내)—

휴식일은 직전 경기와의 날짜 간격에서 경기일을 제외한 수치입니다. 요약 지표는 선택한 경기 기준으로 계산하지만, 각 경기의 직전 일정과 누적 경기 수에는 필터에서 제외한 대회도 포함됩니다.

월간 경기 달력

EPL컵대회휴식 0~2일날짜를 누르면 상세 일정 표시

주간 경기 수는 월요일~일요일 기준입니다. 필터는 표시만 바꾸며 휴식일은 전체 대회를 기준으로 계산합니다.

경기 날짜를 선택해 주세요.

상세 일정

날짜대회상대홈/원정휴식일 / 시각7일·14일
지표 정의와 데이터 한계

7일·14일 경기 수는 해당 경기 날짜를 포함하여 역방향으로 계산합니다. 필터로 숨겨진 대회도 휴식일과 누적 수 계산에 포함되어 있으며, 선택한 조건은 화면에 보이는 행에만 적용됩니다.

시간 단위 간격은 인접한 두 경기에 신뢰 가능한 UTC 킥오프 시각과 검증 출처가 함께 있을 때만 표시할 예정입니다. 같은 날 중복 경기가 나타나면 원본 자료 충돌 가능성이 있으므로 주의 표시합니다. 경기 이동 거리와 선수별 출전 시간은 반영되지 않았습니다.
